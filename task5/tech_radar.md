# Технический радар

## Языки и фреймворки

| Технология               | Статус | Обоснование                                                     |
|--------------------------|--------|-----------------------------------------------------------------|
| Python                   | Adopt  | Язык исполнения ИИ сервисов, ML/AI задачи                       |
| Golang                   | Adopt  | Язык исполнения Финтех сервисов, для высоконагруженных сервисов |
| Java                     | Adopt  | Язык исполнения Финтех сервисов, богатая инфраструктура         |
| Стек доменных приложений | Assess | Выбор языка/фреймворка — на уровне каждого Bounded Context      |

## Инструменты

| Технология                             | Статус | Обоснование                                                                  |
|----------------------------------------|--------|------------------------------------------------------------------------------|
| Schema Registry (Confluent / Apicurio) | Adopt  | Контроль схем междоменных событий; снижение риска нарушения контракта        |
| Kafka Connect                          | Adopt  | Stream Saver: доставка потока событий в LakeHouse (Bronze / Silver)          |
| Power BI                               | Adopt  | Визуализация по Gold-витринам; привычный инструмент для HQ-отчётности        |
| Parquet                                | Adopt  | Стандартный columnar-формат для Bronze / Silver / Gold                       |
| Data Catalog                           | Trial  | Discovery и метаданные для Self-Service Portal; зависит от зрелости каталога |
| Self-Service Portal                    | Trial  | Каталог данных и конструктор отчётов, ключевая фича                          |
| Apache Iceberg                         | Trial  | Формат таблиц LakeHouse; ACID и эволюция схем                                |

## Платформы

| Технология   | Статус | Обоснование                                                       |
|--------------|--------|-------------------------------------------------------------------|
| Apache Kafka | Adopt  | Шина доменных событий; замена Camel/ESB                           |
| Apache Spark | Adopt  | Datamart Builder: построение Gold-витрин из Silver                |
| S3           | Adopt  | Объектное хранилище LakeHouse                                     |
| Apache Flink | Trial  | Near-real-time потоки и предопределённые streaming-витрины в Gold |
| Central DWH  | Hold   | Legacy; вывод к году 3 после миграции на LakeHouse                |
| ESB (Camel)  | Hold   | Legacy; замена доменными сервисами и Kafka                        |

## Методы

| Технология                         | Статус | Обоснование                                                                        |
|------------------------------------|--------|------------------------------------------------------------------------------------|
| Cloud infrastructure               | Adopt  | Гибкость, масштабируемость, переносимость в новые регионы                          |
| Per-region domain instances        | Adopt  | Clinical, AI, Fintech — локальные инстансы; соответствие региональной сертификации |
| Domain-Driven Design (DDD)         | Adopt  | Четыре домена, Bounded Context, агрегаты, инварианты, ACL, OHS, Conformist         |
| Event-Driven Architecture          | Adopt  | Междоменная интеграция через события вместо ESB                                    |
| Data Mesh                          | Adopt  | Данные это продукт и владени ими и витринами переходит внутрь домена               |
| Domain data ownership              | Adopt  | Данные и хранилища в домене-источнике - замена общего DWH                          |
| Self-service BI                    | Trial  | Портал самообслуживания для увеличения TTM аналитики                               |
| Lakehouse                          | Adopt  | S3 + Iceberg + Catalog — целевая аналитическая платформа                           |
| Medallion (Bronze / Silver / Gold) | Adopt  | Слои данных; фильтрация PHI/PII на Silver                                          |
