# Агрегаты

Одинаковые термины в разных Bounded Context — разные модели. Связь — через идентификаторы на границе контекстов, без общей БД.

| Bounded Context   | Агрегат                      | Ключ              | Граница                                                                  | Инварианты                                                                                            | Ссылки                                                   |
|-------------------|------------------------------|-------------------|--------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------|----------------------------------------------------------|
| **Клинический**   | Пациент                      | `patientId`       | PII, договоры, согласия                                                  | Согласие на передачу в ИИ домен — до направления и проактивного мониторинга                           | `globalId?`                                              |
| **Клинический**   | Карточка пациента            | `medicalRecordId` | PHI, исследования, результаты, история приёмов, диагнозы                 | Одна активная карточка на `patientId`                                                                 | `patientId`                                              |
| **Клинический**   | Услуга                       | `serviceId`       | Дата, специалист, статус, способ оплаты                                  | Привязана к `patientId`                                                                               | `patientId`                                              |
| **Клинический**   | Диагностическое исследование | `diagnosticsId`   | Направление, результат, исполнитель                                      | Направление на ИИ диагностику — при наличии согласия                                                  | `patientId`, `medicalRecordId`                           |
|                   |                              |                   |                                                                          |                                                                                                       |                                                          |
| **ИИ**            | Пациент                      | `patientId`       | Профиль, клинические данные без контактных PII, проведённые исследования | Профиль создаётся по направлению или событию карточки (проактивный поток); контактные PII не хранятся | `clinical.patientId`, `globalId?`                        |
| **ИИ**            | Исследование                 | `diagnosticsId`   | Направление, результат                                                   | Связано с `patientId`                                                                                 | `patientId`, `clinical.diagnosticsId`                    |
|                   |                              |                   |                                                                          |                                                                                                       |                                                          |
| **Финтех**        | Клиент                       | `clientId`        | Личность, PII, документы, KYC, договоры с банком                         | KYC до открытия счёта                                                                                 | `globalId?`                                              |
| **Финтех**        | Счёт                         | `accountId`       | Счёт, баланс, транзакции                                                 | Принадлежит одному `clientId`                                                                         | `clientId`                                               |
| **Финтех**        | Кредит                       | `creditId`        | Заявка, договор, процесс, активный кредит                                | Решение учитывает финансовую историю                                                                  | `clientId`                                               |
| **Финтех**        | Финансовая история           | `historyId`       | Рейтинг, открытые кредиты, сводка по счетам, траты                       | Обновляется при изменениях Счёт / Кредит                                                              | `clientId`                                               |
|                   |                              |                   |                                                                          |                                                                                                       |                                                          |
| **Корпоративный** | Клиент                       | `globalId`        | Глобальный идентификатор, номера договоров, согласия                     | Максимум одна связка на локальный идентификатор для каждого домена                                    | `clinical.patientId?`, `bank.clientId?`, `ai.patientId?` |
| **Корпоративный** | Сотрудник                    | `employeeId`      | Должность, доступы                                                       | Привязан к дочернему предприятию                                                                      | `subsidiaryId`                                           |
| **Корпоративный** | Дочернее предприятие         | `subsidiaryId`    | Адрес, юр. лицо, сфера деятельности, статус                              | —                                                                                                     | —                                                        |
| **Корпоративный** | Отчёт                        | `reportId`        | Процесс подготовки и сдачи регламентированной отчётности                 | Строится на событиях доменов                                                                          | `subsidiaryId?`                                          |
